# [Präsentation öffnen: aiiffwfaswfasfdsf.github.io/universum-praesentation](https://aiiffwfaswfasfdsf.github.io/universum-praesentation/)

**Vom heißesten Moment zur ewigen Kälte:** eine animierte Präsentation über den Anfang des Universums und den Kältetod, mit echten Weltraumbildern und ohne nötiges Physikwissen. Auf jeder Folie steht unter „Was ich dazu sagen kann“ ein Vortragstext.

## Auf dem iPad

Tippe oben auf den Link. Die Seite öffnet sich in Safari, du musst nichts installieren oder eintippen. Mit dem Finger wischst du von Folie zu Folie.

Für den schnellen Zugriff: In Safari auf Teilen tippen, dann auf „Zum Home-Bildschirm“.

## Herunterladen

[ZIP herunterladen](https://github.com/aiiffwfaswfasfdsf/universum-praesentation/archive/refs/heads/main.zip) und darin `index.html` öffnen.

Am PC läuft die Datei direkt im Browser. Das iPad öffnet sie meist nur in seiner Vorschau, und dort laufen keine Skripte. Auf dem iPad ist der Link oben deshalb der bessere Weg.
